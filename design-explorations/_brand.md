# Exercise Timer exploration style

Captured November 18, 2026. The repository has no separate design-system document. The light palette in `src/ui.rs` supplies the window gray, grouped white surfaces, system blue and phase colors. The previews use tabular monospaced digits, a circular dial, compact controls and the grouped settings from the regular view. Window sizes come from `src/main.rs`.
