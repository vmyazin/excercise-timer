# Exercise Timer 0.4.0

- Save a Custom or Bodyweight setup by name. Pin a favorite to start it in one click from the setup screen.
- Choose **Repeat last workout** after reopening the app to start the same intervals again from the beginning. Routines, pins, and the last workout are stored on your Mac.
- Press **F** for the across-the-room view. A large countdown shows the current movement and what comes next. The display stays awake during a full-screen workout.

If you have 0.3.0, choose **Exercise Timer → Check for Updates…**. For a fresh install, download the universal DMG, open it, and drag **Exercise Timer** into **Applications**.
