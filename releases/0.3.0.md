# Exercise Timer 0.3.0

Exercise Timer can now check for new versions and install them directly in the app.

- Choose **Exercise Timer → Check for Updates…** in the macOS menu bar.
- Automatic checks run daily and can be turned off in the same menu.
- Updates require your confirmation before installation, and downloaded updates are verified with an Ed25519 signature.
- If a workout is active, a requested update restart waits until the workout finishes or you stop it.

## Install

Download the universal DMG, open it, and drag **Exercise Timer** into **Applications**. The app supports Apple Silicon and Intel Macs running macOS 12 or later and is Developer ID signed and notarized by Apple.

**Upgrading from 0.2.0:** install this release manually once to enable future in-app updates. Workouts continue to work offline.

The ZIP is used by the in-app updater. `appcast.xml` is the update feed; the SHA-256 file contains download checksums.
